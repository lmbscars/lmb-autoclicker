# OP Auto Clicker 4.0

A high-performance, standalone Windows Auto Clicker featuring the exact UI and settings layout of OP Auto Clicker 4.0.

## 🚀 Executable Location
The standalone executable is located at:
`C:\Users\isabe\.gemini\antigravity\scratch\AutoClicker\AutoClicker.exe`

- **Portable:** Single `.exe` file (~32 KB). No installer, runtime, or Python needed.
- **Embedded Icon:** Custom mouse clicker icon.
- **Ultra-low latency:** Supports high-speed clicking down to 1 millisecond.

---

## 🛠️ Features & Settings

### 1. Click Interval
- Configure hours, minutes, seconds, and milliseconds down to 1 ms.
- **Random offset (±):** Check the box and set a millisecond offset (e.g. ±40ms) to randomize intervals and bypass bot/macro detection in games.
- **`?` Button:** Explains the random offset feature.

### 2. Click Options
- **Mouse Button:** `Left`, `Right`, or `Middle`.
- **Click Type:** `Single` or `Double`.

### 3. Click Repeat
- **Repeat [ X ] times:** Runs for a specified number of clicks and automatically stops.
- **Repeat until stopped:** Clicks continuously until the stop hotkey or button is pressed.

### 4. Cursor Position
- **Current location:** Clicks at your active mouse cursor position.
- **Pick location:** Click the `Pick location` button, click anywhere across your screens to capture exact X, Y coordinates, or enter them manually.

### 5. Hotkeys & Controls
- **Default Hotkey:** `F6` (Toggles Start / Stop globally, even in full-screen games).
- **Hotkey setting:** Click `Hotkey setting` to customize the start/stop key (F1-F12, letter keys, etc.).
- **Record & Playback:** Click `Record & Playback` to open the macro recording window where you can record sequences of mouse movements/clicks and replay them in loops.

### 6. Settings Persistence
- Settings automatically save to `autoclicker_config.ini` in the same directory upon closing so your configuration is remembered next time you run it.
